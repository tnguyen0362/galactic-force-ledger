## 4. Combat, weapons and class balance
Server-authoritative combat, client-predicted animation/muzzle flash/audio only. All standard bullets and alien plasma rifles use hitscan with cosmetic tracers (no bullet drop/leading); grenade launcher and rocket launcher use actual simulated explosive trajectories. Right-shoulder parallax: camera aim ray selects point, server traces from validated muzzle to point, near wall blocks shot. Never allow firing through solid cover; no penetration system beyond explicit armor multipliers. Light recoil, responsive immediate trigger, modest accumulated bloom, aim improves accuracy. Baseline recoil decay 7/s, capped angular bloom 2.5× starting spread; sprint ends on fire; no snap aim on mouse. Mobile/controller aim friction and moderate attraction to visible enemy within 5° and 120 studs, cap correction 12°/s, never through wall, never select target behind reticle or guarantee hits. Tune by device testing. Enemy body hit x1, head/marked weakpoint x1.5; boss parts use defined coefficients. Shield first, no ordinary head bonus on shield; overflow damage to health. Enemy armor multiplier on health only. Damage model starts from `raw = baseDamage * rangeFactor * (1 + sum(additiveDamageTraits))`. Apply shield-specific factor to raw damage against shield first; if shield breaks, consume only `shieldBefore/shieldFactor` raw damage, then apply hitMultiplier and armorFactor to remaining raw damage against health. For an unshielded target `D = raw * hitMultiplier * armorFactor`. Apply weakpoint bonuses only where defined; use the modifier caps below. Unit-test partial shield overflow, shield-only hits and component damage so the same raw damage is never charged twice. Falloff linear from 1 at start to minimum at end; reject beyond max range; shotgun per pellet, explosion radial factor `max(0, 1 - 0.75*d/R)` if within R with occlusion ray and no damage beyond R. No stacking area hits on multiple parts of same target. No complex limb damage or ragdoll gore. Primary/secondary magazines use remaining ammo retention: reload `n=min(capacity-mag,reserve)`, subtract reserve, add n after animation commits; cancel before commit has no effect, after commit persists. Empty auto reload; manual anytime; switch cancels reload; 0.4s weapon swap; firing blocked until equipped, not until visual animation finishes if timing differs. Limited ammo/reserve and supply; no paid ammo advantages. Semi-auto needs discrete trigger, auto controlled by rate. Validate ammo, RPM, sequence number, shot origin/aim, equip, life state, timestamp bounds and plausible movement. Client cannot supply hit target/damage. Use bounded timestamp sanity, no blind rewind through cover. Server confirms actual damage/hitmarker and kills. Prevent duplicate shot IDs and impossible hit rate; never kick based on one latency anomaly.

## 6. Enemy AI, threat director and bosses
**Authority/architecture:** server AI uses hierarchical finite state machines and shared spatial grid (e.g. 64-stud cells); role configuration defines range, health/shield, reaction delay, damage, burst timing, attack telegraphs, detection. States Dormant → Patrol/Guard → Investigate → Acquire → Engage (cover/move/peek/fire) → Search → Return; substate for role windup and recover; death terminal. Run no per-NPC Heartbeat connection or full Workspace scan; central staggered scheduler, active decision tick 5 Hz, aim/action 10 Hz, far dormant/investigation 1 Hz, movement via engine path following. Do not change combat decisions on clients. Use bounded line-of-sight raycast from head to torso/head candidates (2 max per selected check), broad-phase nearby cells. Sight 110 studs, 110° cone unless alerted, near proximity 14 studs, hearing unsuppressed gunfire within 90 studs with position uncertainty ±8; explosions 140. Reaction delay uniform .25–.6s Normal, .5–.9 Easy, .2–.45 Hard, .15–.35 Extreme. Record lastSeenPos/time and confidence `exp(-age/4)`; lose exact position when LOS breaks, search last known area <=10s then return. Shared radio knowledge only within 100 studs of same local group or functioning relay, delay .5s, never exact omniscient tracking. Footstep sound not needed for stealth system. Target scores `0.40*visibility + 0.25*(1-clamp(dist/range,0,1)) + 0.20*recentThreat + 0.15*rolePreference`, each term 0..1, target switch hysteresis .15 and 2s minimum hold except invalid target. Downed not targets while active targets exist; no purposeful spawn camping.

**Movement/cover:** precompute POI cover nodes with outward normals, peek and hidden points, tactical flank routes; score candidates by LOS when peeking, concealment, path distance, role preferred range, ally spacing and recent reservations. Reserve one NPC per node with TTL, choose top 3 candidates, fallback local strafe/advance if path fails. Pathfinding request only if destination changed >8 studs, blocked or stale; global token bucket initial 8 paths/s (burst 4), max one in flight per NPC, stagger and cancel stale result. Local obstacle steering, no full nav recompute every frame. If stuck >2s recalc, >6s retreat to safe nearby reachable node (no visible teleport); despawn/recycle only if far and unseen, no loot payout. AI checks LOS immediately before every shot. Burst spread/delay sampled deterministically server-side; never shoot through terrain; missed shots still visibly animate. Use different silhouettes, posture, attack timing and sounds; no identical reskin enemy variants.
